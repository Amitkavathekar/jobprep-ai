# 🤖 JobPrep AI — AI-Powered Job & Interview Preparation Platform

A modern and responsive **AI-Powered Job & Interview Preparation Platform** built using **next.js, TypeScript, and Tailwind CSS v4**.

JobPrep AI helps job seekers prepare for their careers with AI-assisted **resume building, ATS analysis, job matching, mock interviews, skill gap analysis, interview preparation, and personalized career reports**.

The platform also includes **membership management, Razorpay payment integration, support ticketing, coupon management, and an admin control panel**, demonstrating modern frontend architecture and real-world application development.
